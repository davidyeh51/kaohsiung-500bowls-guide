## 📜 評選標準與評選制度說明
「500碗」由《500輯》策劃，被譽為台灣版小吃指南，強調**第一份由台灣人觀點出發**的美食評鑑。邀請50位橫跨名廚（江振誠、簡天才、Nobu Lee等）、世界麵包冠軍（吳寶春）、作家、音樂人、生活家的跨界專業評審，每人各投出心目中最具代表性的10碗小吃。

### 碗數代表之意義：
1. **🏆 2碗得主（跨界評審共同推薦）**：同時征服至少兩位專業領域各異之評審，代表老手藝與精湛火候深受跨世代認可，為高雄最不容錯過的招牌代表。
2. **⭐ 1碗得主（評審專屬私房推薦）**：各評審傾注個人生命記憶與品味推舉的極致風味，展現高雄深厚的飲食文化多元性。
