## 🌟 核心特色：全台首創「500碗 ✕ 米其林」雙榜共構平台

1. **雙榜合璧・橫跨平民小吃與精緻頂級盛宴**：
   - **在地視角【500碗】**：第一份由台灣在地跨界評審（名廚、美食家、藝文生活家）共同評選的 74 間街頭殿堂小吃。

   - 特別標記同時榮膺「500碗」與「米其林必比登／入選」的 7 家傳奇名店（北港蔡三代筒仔米糕、正宗鴨肉飯、侯記鴨肉飯、旗山秀明豬心冬粉、鄭家切仔麵、阿惠虱目魚、楊家肉圓刈包）。
3. **個人「拜訪打卡護照」**：
   - 快速切換「✅ 我去吃過了」與「⏳ 口袋名單」。
   - 記錄拜訪日期、美味星等（1~5星）、實點菜色與感言心得。
   - 即時計算攻略解鎖進度（如「已解鎖 15 / 131 間」）。
   - **一鍵匯出至 Obsidian**：自動格式化為 Markdown 筆記表格。
4. **即時 Google 地圖導航 ＆ 互動全景地圖**：
   - 每間餐廳均建置專屬 Google 地圖精準搜尋與一鍵導航連結。
   - 整合 Leaflet.js 互動地圖，依「500碗（橘色）」、「米其林（紅色）」及「已打卡（綠色）」分類呈現。
5. **本機 LocalStorage ＋ Supabase 雲端同步雙軌支援**：
   - 預設 100% 隱私本機儲存，零設定即開即用。
   - 亦可填入個人 Supabase Project URL 與 Key，享受多裝置無縫即時同步。

- **直接使用**：打開 [GitHub Pages 線上互動平台](https://davidyeh51.github.io/kaohsiung-500bowls-guide/)，即可以手機或電腦瀏覽名冊、切換分區篩選、觀看圖片與開啟地圖。
- **打卡記錄**：
  1. 點擊任一名片上的「📝 打卡記錄 / 口袋名單」。
  2. 選擇造訪日期、給予評分（1~5星）、填入點購菜色與私房心得。
  3. 點擊「儲存打卡」，名片立即更新為綠色「已打卡品嚐」標籤，地圖圖針亦變更為已訪標記。
  4. 隨時可利用右上角「匯出打卡紀錄至 Obsidian」複製純 Markdown 清單保存！
